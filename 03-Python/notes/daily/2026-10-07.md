## 学习内容

- **数据范围就是提示**：n ≤ 10^100 → 不能循环 → 一定有公式（结论题）。看到离谱的范围，先想结论，不要写循环。
- **P2 的结论**：找「编号最大、且和 n 互质」的数 —— 相邻两个整数不可能有大于 1 的公因数，所以 n−1 一定和 n 互质；n 和自己永远不互质 → 答案就是 n−1（n = 1 单独处理成 1）。
- **`math.gcd(a, b)`**：求最大公因数；互质 = `gcd == 1`。（这题最后没用到，是考场工具）
- **样例过 ≠ 对**：P4 的 `for l in range(1, n)` 漏掉了「从第 1 个元素开始」的区间；P5 少了 `:.1f`。两条都被样例「恰好」躲过了。
- **自测的新判据**：不是「样例过了」，是「我把另一条分支也踩到了」。
- **对拍**：随机造 300 组小数据，跟暴力版逐组比 —— 比只看样例强太多，今天三道错题都是这么现形的。

## 遇到的问题

**问题 1：P2 逻辑方向错 —— 「存在」写成了「全部」**

判据写成「只要**存在**一个 j 不能同时整除 i 和 n，就把 x 设成 i」，所以几乎每个 i 都会覆盖 x，最后 x = n。而 n 和自己的 gcd 永远是 n，永远不可能是答案。
要的是反过来：**所有 j 都除不尽**才算互质。

**问题 2：P2 算法方向错 —— 10^100 还想暴力**

`range(1, n+1)` 数到宇宙毁灭也数不完。n ≤ 10^100 这行字本身就是提示：**不能循环 = 一定有公式**。

**问题 3：P4 区间起点漏了**

`for l in range(1, n)` —— 题目是 1 ≤ l ≤ r ≤ n，**第 1 个元素开头的区间必须有**。反例：`1 组 / n=2 m=3 / 3 4`，只有 `[3]` 自己能整除，应该 Yes，原代码输出 No。
顺手把 O(n²) 换成了 O(n) 的「余数相同」（t09 那套搬过来），极限数据从超时变成 370 毫秒。

**问题 4：P5 忘了小数位格式**

样例正好整除（16.0）所以看不出来。换 `A 10 / A 11 / A 11` → 原代码输出 `10.666666666666666`，应该是 `10.7`。

## 今天理解最重要的一点

**数据范围是题目给你的第一句提示，不是废话。**

前几天的坑都是「代码写错」，今天这个更上一层：**方向错**。P2 的代码怎么调都对不了 —— 因为暴力的路本身走不通。所以拿到题先看范围：

- n ≤ 10^5 → 循环 / 排序 / 二分都可以
