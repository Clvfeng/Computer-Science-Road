## 学习内容：双指针 / 滑动窗口（新套路）

**什么时候想它**：题目同时出现「**连续**子段 / 区间」+「全是**正数**」+「求**最短** / 最长」。

**为什么成立**：数组全是正数 → 窗口往右扩和一定变大，左边往右缩和一定变小。**有负数就不成立**，所以"全是正数"这个条件不是废话，是暗号。

**动作就两步**：

1. 右手一直往右走，每走一步把数加进 `window_sum`
2. 每加完一个数，**只要还满足"和 ≥ S"就把左手也往右收**，一边收一边更新答案

```python
left = 0
window_sum = 0
ans = n + 1                 # "还没找到"的标记
for right in range(n):
    window_sum += a[right]
    while window_sum >= S:          # ★ while，不是 if
        ans = min(ans, right - left + 1)
        window_sum -= a[left]
        left += 1
print(ans if ans <= n else -1)
```

**三个易错点**：

- 收缩用 `while` 不是 `if`（可能连着缩好几步），这是最容易写错的地方
- 长度 = `right - left + 1`（含头含尾）
- `ans` 初值 `n + 1`，"没找到"输出 `-1` —— 又是「先给一个不可能的值」这个手法

**复杂度 O(n)**：左右指针都只往右走、不回头，各走 n 步。

**这次填四个空全对、一次过。** 对比 10/9 那两题各改两轮 —— 说明"先讲清前提（为什么全是正数才行）+ 骨架给出结构"这种方式对你有效。
