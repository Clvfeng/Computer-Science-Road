## 学习内容

### 装饰器 @ 的本质
@xxx 等价于：函数 = xxx(函数)
- @property → 方法变属性（不加括号）
- @staticmethod → 变成静态方法（不需要 self）
- @classmethod → 接收 cls 参数（知道当前类）

### @property 三用法
1. 约束（@setter 校验）
2. 只读（不写 setter）
3. 计算属性（实时拼接）

### 虚拟环境
- venv = 独立的小 Python，每个项目一个
- 激活后 pip install 只装到当前项目
- deactivate 退出，互不干扰

## 遇到的难点

### 1. 用了很多次 @staticmethod 但一直不理解
- 原因：我直接让用，没解释 @ 是什么
- 搞懂后：@ = 装饰器，把函数改造后返回
- 不必背，需要什么功能查对应的 @xxx 就行

### 2. @score.setter 的命名规则
- @score.setter 里的 score 来自上面 @property def score
- 不是随便起的，属性名叫什么 .setter 就叫什么

### 3. Windows 执行策略阻止运行脚本
- 解决：Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
- 遇到这种问题先搜或问我，不硬扛

## 今天理解最重要的一点
装饰器 @ 不是玄学，就是"把函数改造一下"的语法糖。
