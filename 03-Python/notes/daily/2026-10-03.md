## 学习内容

- **前缀和**：`pre[i]` = 前 i 个数的和，`pre[0] = 0`；区间和 = `pre[r] - pre[l-1]`
- **同余等价**：`pre[r] - pre[l-1]` 是 m 的倍数 ⟺ `pre[r]` 与 `pre[l-1]` 模 m 余数相同
- **集合 set 查重**：`set()` / `.add()` / `in`，O(1)
- **鸽巢原理**：n+1 个余数只有 m 种可能，n ≥ m 时必然重复 → 答案一定 Yes
- **对拍**：拿暴力版当标准答案，随机造小数据两边对比
- `range(a, b)` 含头不含尾；Python 列表**不能隔空赋值**

## 遇到的问题

**问题 1：暴力版把数组读成了 n 行**

原因：题目是「第二行 n 个整数」（一行），写成 `for _ in range(n): values = list(map(int, input().split()))`
→ 读了 n 行，而且每轮覆盖 `values`，把后面几组测试的数据也吃了进来
→ `values` 变成 `[7, 8]`，再用 `values[4]` 访问 → `IndexError`

定位方法：见 `IndexError` 先想「下标超界」，接着问「我的列表到底装了什么、多长？」
→ 打印 `values, len(values)` 立刻真相。

**问题 2：`print("No")` 写在 `for l` 循环里面**

原因：外层循环跑几次就打印几次；而且找到 Yes 之后外层没停
解决：用 **flag 标记**，所有循环走完再统一输出一次

**问题 3：`pre = []` 之后 `pre[0] = 0` → IndexError**

原因：**Python 列表不能隔空赋值**，必须先长出来（`append`）；这和 C 里可以 `int pre[10000]` 先占位完全不同
解决：改用累加变量 `pre = 0`。更关键的是 —— 这个列表**本来就是多余的**，我只需要"当前累加到多少"这一个数字

## 今天理解最重要的一点

**「存不存在」的问题，可以换算成「查重」的问题。**

原来要枚举 n²/2 ≈ 5000 万个区间；把"区间和"换成"两个前缀和相减"之后发现：
只要两个前缀和**余数相同**，中间那段就合格 → 根本不用枚举区间，只要一边扫一边问"这个余数见过吗"。
5000 万次 → 1 万次。

关键动作是**换表示**：同一个东西（区间和）换个写法（两个前缀和相减），题目难度就变了。
"换个角度"的题在天梯赛里非常常见 —— 卡住的时候可以问自己：**这个东西还有别的写法吗？**
