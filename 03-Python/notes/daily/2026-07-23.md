## 学到的知识

### Python语法

- f-string 中表达式要用 `{}` 包裹，如 `f"{num1}+{num2}={num1+num2}"`
- input() 函数用于接收用户输入，返回字符串
- float() 可将字符串转换为浮点数

### 条件分支

- if-elif-else 结构：elif 替代多个独立 if，更高效
- else 后面不能加条件判断
- break 只能在循环中使用，不能在条件分支中直接用

### 函数

- 用 `def 函数名(参数):` 定义函数
- 函数体用缩进表示，冒号开头
- `return` 返回值，可在函数外部用变量接收
- Python 函数不需要声明返回类型（与 C 语言不同）

## 遇到的问题

### 1. f-string 内表达式未用 {}

初版 calculator.py 中：
```python
print(f"{num1}+{num2}="num1+num2)
```
num1+num2 写在了 f-string 外面，导致语法错误。

修正后：
```python
print(f"{num1}+{num2}={num1+num2}")
```

### 2. else 后面跟条件判断

初版中写了：
```python
else fh == "-" :
```
else 不能带条件，应改为 elif。

### 3. 除数为零处理错误

初版用了 `break`，但 break 只能在循环中使用。
修正为用 if-else 判断 num2 != 0，输出错误提示字符串。
