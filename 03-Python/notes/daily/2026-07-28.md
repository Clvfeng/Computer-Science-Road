## 学习内容
- class 定义：class 类名: + 缩进
- __init__：构造函数，self 代表对象本身
- 成员变量：self.变量名
- 成员方法：def 方法名(self, ...)，self 必须是第一个参数
- @staticmethod：静态方法，不需要 self
- to_dict / from_dict：对象 ↔ 字典的转换
- 列表推导式：[s.to_dict() for s in students]

## 对比 C++ 和 Python
- C++ 的 this 是隐式的，Python 的 self 要显式写
- C++ 有 public/private，Python 靠命名约定
- C++ 需要声明类型，Python 直接写
