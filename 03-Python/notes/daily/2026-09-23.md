## 学习内容

- `input()` 返回字符串，参与计算前必须 `int()` 转换
- 一行读多个数：`a, b = map(int, input().split())`
- `map()` 返回的是迭代器（加工厂），要 `list()` 装起来才是列表
- 字符串下标与切片 `[开始:结束:步长]`，含头不含尾，`s[::-1]` 倒序
- `print(值1, 值2)` 默认用空格分隔
- `sum()` 与 for 循环累加两种求和方式

## 遇到的问题

问题 1：把代码粘进 Python 交互模式（`>>>`）运行，报 `ValueError: invalid literal for int() with base 10: 'print(a+b)'`

解决：`input()` 读的是键盘输入，交互模式下会把后面粘进去的代码当成输入吃掉。带 `input()` 的程序必须存成文件再运行。

问题 2：`n = map(int, input("..."))`，报 `TypeError: 'int' and 'map'`

解决：读单个整数用 `int(input())`；`map` 要用在「一行多个数」的场景，并且外面必须套 `list()` 或 `a, b =`。

问题 3：`s[4,0,-1]` 报错，改成冒号后输出 `olle` 少一个字母

解决：方括号里分隔符是冒号不是逗号；数字 4 是写死的，长度一变就崩，应该用负数下标；结束位置填 0 因「含头不含尾」被排除，所以开始结束全部省略写成 `s[::-1]`。

问题 4：`for i in n` 报 `'int' object is not iterable`；`list() = map(...)` 报 `cannot assign to function call`

解决：`n` 是数字不是一串东西，Python 直接遍历容器本身不需要下标；`list` 是工具不能赋值，结果要存进变量。

问题 5：`sum = 0` 遮住了 Python 自带的 `sum()` 函数

解决：内置函数名不能拿来当变量名，改用 `total`。

问题 6：`tolal = sum(s)` 但 `print(tol)` 报 `NameError`

解决：变量名逐字比较，差一个字母就是另一个名字。

问题 7：`sum(list)` 报错

解决：`list` 是转换工具，数据存在变量 `s` 里，应该用 `sum(s)`。

## 今天理解最重要的一点

读懂「一串」和「一个」的区别：`n` 是一个数字，`s` 是一串数据。`for` 只能遍历一串，`sum()` 只能接受一串。C 语言里习惯用下标 `a[i]` 一个个取，Python 是直接遍历容器本身 —— 这是从 C 转到 Python 最容易混的地方。
