## 学习内容
### 模块化
- 每个文件一个职责：student（数据）、storage（存储）、menu（操作）、main（入口）
- import 方式：from 文件名 import 函数名
- 模块间依赖链：main → storage/menu → student

### 文件读写（之前没理解，今天搞懂了）
- json.dump(数据, 文件对象) — 写出去，两个参数
- json.load(文件对象) — 读进来，一个参数
- with open(...) as f: — 自动关闭文件
- "w" = 写入模式，"r" = 读取模式

### 本项目结构
```
student_manager/
├── main.py        # 入口
├── student.py     # Student 类
├── storage.py     # JSON 读写
├── menu.py        # 菜单操作
└── data.json      # 自动生成
```

## 遇到的问题

### 1. json.dump 参数顺序记不住
- 理解后记住：dump(要存的数据, 存到哪里去)
- 和中文一样：dump(东西, 文件)

### 2. with open 语法不熟
- 固定写法：with open(文件名, 模式, encoding="utf-8") as f:
- 记住模板，多写几次就熟了

### 3. from_dict 和 to_dict 的作用不清晰
- to_dict：Student 对象 → 字典（为了存到 JSON）
- from_dict：字典 → Student 对象（为了从 JSON 读回来）

### 4. 文件不存在时 try/except 的作用
- 第一次运行 data.json 不存在，open() 会报错
- try→尝试打开，失败→except→返回空列表 []

## 今天理解最重要的一点
模块化就是把不同职责的代码分开，每个文件只管一件事。main.py 负责组装，不关心 student.py 内部怎么实现。
