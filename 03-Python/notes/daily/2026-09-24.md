## 遇到的问题

问题：t06 第一版的输入部分读法全错

- 数组是一整行，却写成了循环读 n 行
- 对空列表用下标赋值：`num[0] = ...` → IndexError
- 查询每行只有一个数，却按两个数读
- `num[i+1]` 越界

解决：把三个阶段（读输入 / 建字典 / 处理查询）分开写，一段一段验证，读输入后先 print 出来确认。

## 今天理解最重要的一点

**空列表不能用下标赋值** —— 里面一个格子都还没有，只能用 `append` 或者一次读成列表。
