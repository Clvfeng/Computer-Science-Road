# P1 翻转与统计

给一个只含英文字母和数字的字符串 s（不含空格，长度 ≤ 1000）。

输出两个东西，空格分开：
1. 把 s **逆序**后的字符串
2. s 中**大写字母**的个数

输入：第一行 T（1 ≤ T ≤ 100），接下来 T 行，每行一个字符串 s
输出：T 行，每行 `逆序串 大写个数`

样例输入：
```
2
aBcDe
xyz
```
样例输出：
```
eDcBa 2
zyx 0
```

# P2 成绩统计

某班有 n 名学生，每人有姓名（不含空格）和一个分数。

输出两行：
1. **分数最高**的学生姓名（若多人并列最高，取**先出现的**那个）
2. 全班**平均分**，保留 **2 位小数**

输入：第一行 n（1 ≤ n ≤ 1000），接下来 n 行，每行 `姓名 分数`
输出：两行

样例输入：
```
4
Amy 88
Bob 95
Cara 95
Dan 62
```
样例输出：
```
Bob
85.00
```

# P3 01 串取反

给一个只含 `0` 和 `1` 的字符串。

每次操作可以选一个**连续区间**，把区间内的字符**全部取反**（0 变 1，1 变 0）。

问：最少需要多少次操作，能让整个串变成**全 0**？

输入：一行一个 01 串（长度 ≤ 10^6）
输出：一个整数

样例输入：
```
101
```
样例输出：
```
2
```

# P4 最多能参加几个活动

有 n 个活动，第 i 个活动的时间是 `s[i]` 到 `e[i]`。

同一个人同一时间只能参加一个活动（**前一个活动结束的瞬间可以开始下一个**）。

问：最多能参加几个活动？

输入：第一行 n（1 ≤ n ≤ 100000），接下来 n 行，每行 `s e`
输出：一个整数

样例输入：
```
4
1 3
2 5
4 6
6 7
```
样例输出：
```
3
```

# P5 食堂窗口

食堂只有一个窗口。有 n 个人**按顺序**来到窗口前，第 i 个人在时刻 `t[i]` 到达，打饭需要 `w[i]` 分钟。

规则：
- 窗口空着 → 到达后**立刻**开始打饭
- 窗口有人在打 → **排队等**，等前一个人打完才开始

输出每个人**开始打饭的时刻**，每人一行。

输入：第一行 n（1 ≤ n ≤ 100000），接下来 n 行，每行 `t w`
输出：n 行

样例输入：
```
3
0 5
2 3
10 1
```
样例输出：
```
0
5
10
```

# P6 最短子段

给一个长度为 n 的**正整数**数组，再给一个目标值 S。

问：和**大于等于 S** 的**连续子段**里，最短的长度是多少？

如果不存在这样的子段，输出 `-1`。

输入：第一行 n S（1 ≤ n ≤ 100000，1 ≤ S ≤ 10^9），第二行 n 个正整数
输出：一个整数

样例输入：
```
6 7
2 3 1 2 4 3
```
样例输出：
```
2
```
