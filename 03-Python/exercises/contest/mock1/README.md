# P2 智能灯泡

小明有 n 个灯泡，编号 1 到 n。他想点亮其中一个灯泡 x，要求
**x 与 n 互质**（即 gcd(n, x) = 1），并且 1 ≤ x ≤ n。

如果存在这样的 x，输出编号最大的那个 x；如果不存在，输出 -1。

输入：第一行 T（T ≤ 10000），接下来 T 行，每行一个整数 n（1 ≤ n ≤ 10^100）
输出：每组一行

样例输入：
```
3
2
1
10
```
样例输出：
```
1
1
9
```

# P4 鸽巢（前缀和）

一只鸽子住一个鸽巢，总共有 n 个鸽巢，每只鸽子都有自己的价值 a[i]。
养鸽人小云想拎出一个连续区间 l ~ r 的鸽子售卖，他希望卖出的价格是 m 的倍数
（1 ≤ l ≤ r ≤ n）。小云只会养鸽子不会数学，需要你告诉他这能不能做到。

输入：
第一行 T（1 ≤ T ≤ 100）
每组两行：第一行 n m（n ≤ 10^4，m ≤ 10^9）；第二行 n 个整数 a[i]（a[i] ≤ 10^7）
输出：每组一行，可以做到输出 `Yes`，否则输出 `No`

样例输入：
```
3
5 3
1 2 3 4 5
3 100
1 2 4
2 1
7 8
```
样例输出：
```
Yes
No
Yes
```

# P5 图书馆统计

某图书馆统计一周内的图书借阅情况，要找出**最受欢迎的图书类别**（借阅次数最多），
并计算该类别的**平均每次借阅时长**。

已知：
- 图书分 3 类：A（文学）、B（科技）、C（教辅）
- 若多个类别借阅次数并列最多，选**类别字母最小**的那个
- 平均时长保留 **1 位小数**

输入：
第一行一个整数 n（借阅记录条数，1 ≤ n ≤ 1000）
接下来 n 行，每行一个字母（A/B/C）和一个整数（借阅时长，1 ≤ 时长 ≤ 72），空格分开

输出两行：
```
Most popular: X
Average time: Y
```

样例输入：
```
4
A 10
B 20
C 30
B 12
```
样例输出：
```
Most popular: B
Average time: 16.0
```

# P6 查下标（二分）

给定一个按照升序排列的长度为 n 的整数数组，以及 q 个查询。
对于每个查询，返回元素 k 在数组中的起始位置和终止位置（位置从 0 开始计数）。
如果数组中不存在该元素，则返回 `-1 -1`。

输入：
第一行 n q（1 ≤ n, q ≤ 100000）
第二行 n 个整数
接下来 q 行，每行一个整数 k
输出：q 行，每行两个整数

样例输入：
```
6 3
1 2 2 2 3 5
2
4
5
```
样例输出：
```
1 3
-1 -1
5 5
```
